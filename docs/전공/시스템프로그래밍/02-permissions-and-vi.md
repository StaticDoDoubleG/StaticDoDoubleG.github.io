## `ls -l` 권한 표기

파일마다 읽기, 쓰기, 실행 권한이 있고 권한의 대상은 소유자(user), 그룹(group), 그 외 사용자(others)로 나뉜다.

```bash
ls -l hello.c
```

권한 문자열의 기본 의미는 다음과 같다.

- `r`: 내용을 읽거나 디렉터리 목록을 읽을 수 있음
- `w`: 파일 내용을 수정하거나 디렉터리 항목을 변경할 수 있음
- `x`: 파일을 실행하거나 디렉터리를 탐색할 수 있음

디렉터리에서 `r`만 있다고 내부 항목을 자유롭게 사용할 수 있는 것은 아니다. 디렉터리의 `x`는 해당 경로를 통과하고 항목에 접근하는 권한이며, `w`는 생성·삭제 같은 변경 권한과 관련된다.

## `chmod`

소유자는 `chmod`로 권한을 변경할 수 있다.

```bash
chmod u+x program       # 소유자에게 실행 권한 추가
chmod go-r secret.txt   # 그룹과 그 외 사용자의 읽기 권한 제거
chmod a+r report.txt    # 모든 대상에 읽기 권한 추가
```

권한은 프로그램이 요구하는 최소 범위만 부여해야 한다. 특히 실행 권한과 쓰기 권한을 모든 사용자에게 동시에 열면 실수나 악의적인 변경의 범위가 커진다. ~그러나 LXC는 귀찮아서 root로 만지지~ <- 이려면 큰일납니다. 어린이 여러분은 이러지 마세요.


### 숫자 표기 예시

```bash
$ chmod 640 report.txt
$ ls -l report.txt
-rw-r----- 1 student class 120 Oct 17 10:00 report.txt
```

`640`은 소유자에게 `rw-`(6), 그룹에게 `r--`(4), 그 외 사용자에게 `---`(0)를 의미한다. 숫자 한 자리는 `r=4`, `w=2`, `x=1`을 더해 만든다. 예를 들어 실행 파일에 소유자 실행 권한만 추가하려면 `chmod 700 program`처럼 지정할 수 있다.

## vi의 모드

vi는 명령 모드와 입력 모드를 구분한다. 파일을 열었다고 바로 문자를 입력하는 것이 아니라, 명령 모드에서 입력 모드로 전환해야 한다. ~정말 적응 안된다.~

```bash
vi hello.c
```

- `i`: 현재 위치에서 입력 모드 시작
- `a`: 현재 문자 다음에서 입력 모드 시작
- `Esc`: 명령 모드로 돌아가기
- `:w`: 저장
- `:q`: 종료
- `:wq`: 저장하고 종료
- `:q!`: 저장하지 않고 강제 종료

이동, 삭제, 복사, 붙여넣기 명령은 모두 명령 모드에서 사용한다. 편집이 되지 않을 때는 먼저 현재 모드가 무엇인지 확인하고 `Esc`를 누른다.

## 파일명과 저장

새 파일을 만들 때도 `vi 파일명`으로 시작한다. `:w 다른파일명`은 현재 편집 내용을 다른 이름으로 저장하면서 기존 편집 화면을 유지하는 방식이다. 저장 여부를 확인하지 않고 `:q!`를 사용하면 변경 내용이 사라진다. 저장하고 나가고 싶으면 :wq 조합으로 나가면 된다. **참 쉽죠?**

### 파일을 만들고 저장하는 흐름

```text
$ vi hello.c
i                 입력 모드로 전환
int main(void) { return 0; }
Esc               명령 모드로 전환
:wq               저장하고 종료
$ cat hello.c
int main(void) { return 0; }
```

문자가 입력되지 않으면 입력 모드가 아닐 가능성이 크고, 종료 명령이 동작하지 않으면 `Esc`를 먼저 누른다. 저장된 결과는 `cat`이나 `less`로 확인한다.
