# 머신러닝 개론과 학습 과정

## 1. 머신러닝의 문제 정의
머신러닝은 사람이 모든 규칙을 직접 작성하는 대신 데이터에서 입력과 출력 사이의 규칙을 추정한다. 입력 특징 $x$를 모델 $f_\theta$에 넣어 예측 $\hat y$를 만들고, 정답 $y$와의 손실을 줄이도록 파라미터 $\theta$를 학습한다.

$$\hat y=f_\theta(x),\qquad \theta^*=\arg\min_\theta J(\theta)$$

## 2. 학습 유형
- **지도학습**: 정답이 있는 데이터. 선형회귀와 분류.
- **비지도학습**: 정답 없이 구조를 찾음.
- **강화학습**: 행동과 보상으로 정책을 개선.

## 3. 회귀와 분류
회귀는 집값·점수처럼 연속적인 값을 출력하고 MSE 같은 거리 기반 손실을 쓴다. 분류는 클래스 또는 클래스 확률을 출력하며 BCE/CCE 같은 확률 기반 손실을 쓴다.

## 4. 일반적인 ML 과정
문제 정의 → 데이터 수집과 전처리 → train/validation/test 분할 → 모델·손실 선택 → 학습 → 검증 → 최종 평가 → 추론의 순서다. 학습 데이터를 반복해 보면서 성능을 올려도 test 데이터는 마지막까지 사용하지 않아야 한다.

## 5. 모델의 세 가지 관점
1. **표현**: 퍼셉트론과 신경망이 어떤 함수를 표현하는가.
2. **평가**: MSE, cross entropy처럼 예측의 좋고 나쁨을 어떻게 수치화하는가.
3. **최적화**: gradient와 optimizer로 파라미터를 어떻게 움직이는가.

이 세 관점을 구분하면 `모델이 틀린 이유`, `손실이 큰 이유`, `학습이 안 되는 이유`를 분리해 진단할 수 있다.

## 4. 지도학습의 표기

데이터셋을 $D=\{(x_i,y_i)\}_{i=1}^N$으로 두면 모델은 각 $x_i$에 대해 $\hat y_i=f_\theta(x_i)$를 만든다. 샘플별 손실을 평균한 목적 함수는
$$J(\theta)=\frac1N\sum_{i=1}^N\ell(f_\theta(x_i),y_i)$$
이다. 학습은 정답을 저장하는 과정이 아니라 이 목적 함수가 작아지는 파라미터를 찾는 과정이다.

회귀에서는 $y$가 실수이고 prediction과 target의 차이를 직접 다룬다. 분류에서는 출력이 class index인지 class probability인지 logits인지 먼저 구분해야 한다. 같은 MNIST라도 모델은 10개 실수 logits를 출력하고, 평가 시에만 가장 큰 index를 class로 해석한다.

## 5. 데이터셋 분할의 의미

train loss가 낮다는 것은 train 샘플의 오차가 작다는 뜻이지, 보지 못한 샘플의 규칙을 학습했다는 뜻은 아니다. validation은 모델 구조와 hyperparameter를 고르는 데 쓰고, test는 선택이 끝난 뒤 한 번 사용한다. test 결과를 보며 계속 모델을 바꾸면 test도 학습 데이터처럼 사용된다.

실제 운영의 시간 방향이나 사용자 단위가 있는 데이터에서는 분할 단위도 보존해야 한다. 같은 사용자의 기록이 train과 test에 동시에 들어가면 사용자를 외우는 방식으로 높은 점수를 얻을 수 있다. train/test 구분은 파일 분리가 아니라 평가 정보가 학습 과정에 역류하지 않도록 하는 경계다.

## 6. 재현성 기록

동일한 코드라도 random initialization, batch shuffle, device, library version에 따라 결과가 변한다. 따라서 모델 결과와 함께 seed, 데이터 분할, batch size, learning rate, epoch, optimizer, 평가 시점을 기록한다. 정확도 하나보다 loss curve와 confusion matrix를 남겨 어떤 종류의 오류가 줄었는지 확인하는 것이 유용하다.
