# 퍼셉트론과 선형회귀

## 1. 퍼셉트론을 파라미터가 있는 판정식으로 보기

퍼셉트론은 입력을 하나의 점수로 바꾸는 affine 계산과 그 점수를 0/1로 자르는 계단 함수의 결합이다.

$$z=w^Tx+b=\sum_iw_ix_i+b$$
$$y=\begin{cases}1&z>0\\0&z\le0\end{cases}$$

여기서 $x$는 관측된 입력이고, 학습을 통해 바뀌는 것은 $w$와 $b$다. $w_i$의 절댓값이 크면 해당 입력 변화가 판정 점수에 크게 영향을 준다. $b$는 모든 입력이 0일 때의 기본 점수이며, 경계가 원점을 지나지 않도록 이동시키는 항이다.

두 입력의 결정 경계는
$$w_1x_1+w_2x_2+b=0$$
이다. 이를 $x_2$에 대해 정리하면 $x_2=-(w_1/w_2)x_1-b/w_2$이므로 평면 위의 직선이 된다. 단층 퍼셉트론은 한 직선의 양쪽을 0과 1로 나누는 모델이다.

## 2. 코드와 수식의 대응

```python
def AND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.7
    tmp = np.sum(w * x) + b
    return 0 if tmp <= 0 else 1
```

`w * x`는 `[w1*x1, w2*x2]`이고 `np.sum`이 내적을 만든다. `tmp <= 0`을 0으로 두는 것은 실습에서 정한 경계 조건이다. AND의 네 입력에서 점수는 `-0.7, -0.2, -0.2, 0.3`이므로 둘 다 1인 경우만 양수가 된다.

같은 가중치에서도 bias를 바꾸면 게이트가 달라진다.

| 입력 | AND: $0.5x_1+0.5x_2-0.7$ | OR: $0.5x_1+0.5x_2-0.3$ |
|---|---:|---:|
| `(0,0)` | -0.7 | -0.3 |
| `(1,0)` | -0.2 | 0.2 |
| `(0,1)` | -0.2 | 0.2 |
| `(1,1)` | 0.3 | 0.7 |

AND는 두 입력의 합이 충분히 커야 하고, OR는 하나만 1이어도 양수가 되어야 한다. NAND는 AND의 판정 조건을 반대로 만들도록 가중치와 bias의 부호를 바꾼다.

## 3. XOR와 다층 조합

XOR의 양성 샘플은 `(1,0)`, `(0,1)`이고 음성 샘플은 `(0,0)`, `(1,1)`이다. 양성·음성 점이 대각선으로 교차하므로 하나의 직선으로 분리할 수 없다. 가중치를 더 잘 찾으면 해결되는 문제가 아니라 단층 퍼셉트론의 가설 공간에 XOR가 없는 문제다.

다층 구성은 중간 표현을 만든다.
```python
s1 = NAND(x1, x2)
s2 = OR(x1, x2)
y = AND(s1, s2)
```

`NAND`는 `(1,1)`만 0으로 만들고 `OR`는 `(0,0)`만 0으로 만든다. 마지막 `AND`는 두 중간 출력이 모두 1인 경우, 즉 XOR의 두 양성 입력만 통과시킨다. 각 퍼셉트론은 여전히 선형 판정이지만, 층을 거치며 원래 입력과 다른 중간 공간을 만들기 때문에 전체 함수는 비선형이 된다.

## 4. 선형회귀의 가설과 데이터

선형회귀는 출력이 0/1로 잘리지 않고 연속적인 값을 그대로 예측한다.
$$\hat y=H(x)=Wx+b$$

실습 데이터는
$$\{(1,5),(2,2),(3,-1)\}$$
이고 세 점 모두 $y=-3x+8$에 있다. 초기 $W=0,b=0$이면 예측은 `[0,0,0]`이고 오차는 `[-5,-2,1]`이다. 학습은 이 오차를 한 번에 정답으로 바꾸는 것이 아니라 MSE의 gradient를 이용해 직선의 기울기와 절편을 조금씩 이동시킨다.

## 5. MSE와 gradient

$$J(W,b)=\frac1n\sum_{i=1}^n(\hat y_i-y_i)^2$$

제곱을 쓰면 양의 오차와 음의 오차가 상쇄되지 않고, 큰 오차가 더 큰 비중을 갖는다. 이 식의 편미분은
$$\frac{\partial J}{\partial W}=\frac2n\sum_i(\hat y_i-y_i)x_i$$
$$\frac{\partial J}{\partial b}=\frac2n\sum_i(\hat y_i-y_i)$$
이다. $W$의 gradient에는 입력 $x_i$가 곱해지므로 큰 입력 샘플이 기울기에 더 크게 기여한다.

경사하강법은
$$W\leftarrow W-\alpha\frac{\partial J}{\partial W},\qquad b\leftarrow b-\alpha\frac{\partial J}{\partial b}$$
로 갱신한다. gradient가 양수면 해당 파라미터를 줄이고, 음수면 늘린다. 학습률 $\alpha$가 너무 크면 최소점을 뛰어넘어 loss가 발산하거나 진동하고, 너무 작으면 수렴까지 많은 반복이 필요하다.

## 6. PyTorch 자동미분 구현

```python
W = torch.zeros(1, requires_grad=True)
b = torch.zeros(1, requires_grad=True)
optimizer = torch.optim.SGD([W, b], lr=0.01)

for _ in range(5000):
    hypothesis = x_train * W + b
    cost = torch.mean((hypothesis - y_train) ** 2)
    optimizer.zero_grad()
    cost.backward()
    optimizer.step()
```

`requires_grad=True`는 연산 그래프에서 tensor를 미분 대상으로 등록한다. `cost.backward()`는 위에서 직접 유도한 미분을 자동으로 계산하고, optimizer는 `W.grad`, `b.grad`를 사용한다. `zero_grad()`가 필요한 이유는 PyTorch gradient가 기본적으로 누적되기 때문이다.

## 7. 결과 검증과 일반화

학습 뒤에는 파라미터 값만 보지 않는다. `x=1,2,3`의 예측이 `[5,2,-1]`에 가까운지 확인하고, 학습에 사용하지 않은 입력값에 대한 예측도 직선의 연장선과 일치하는지 본다. train loss가 작아도 새로운 범위에서 이상한 값을 내면 데이터 범위 밖 외삽의 위험을 기록해야 한다.

퍼셉트론 실습은 사람이 직접 `w,b`를 정해 규칙을 구현하는 과정이고, 선형회귀 실습은 loss와 gradient가 데이터를 보고 `W,b`를 찾아가는 과정이다. 두 실습의 차이는 모델 구조보다 파라미터를 정하는 주체와 학습 가능성에 있다.
