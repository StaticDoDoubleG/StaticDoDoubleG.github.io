## Core Ideas of Machine Learning
머신러닝은 데이터에서 패턴을 학습해 보지 못한 입력에 대한 예측이나 결정을 수행한다. 핵심 목표는 학습 데이터에만 맞는 것이 아니라 새로운 데이터에도 잘 작동하는 **일반화**다.

- **Model**: 입력을 출력으로 매핑하는 함수
- **Data**: 모델이 관찰하는 사례
- **Loss**: 예측과 정답의 차이를 수치화한 값
- **Optimization**: 손실을 줄이도록 파라미터를 바꾸는 과정

AI는 지능적 행동을 다루는 넓은 분야이고<br>
ML은 데이터에서 학습하는 AI의 부분집합이며,<br> 
DL은 신경망을 사용하는 ML의 부분집합이다.

## 2. Learning Paradigms
ML 관련 교양을 찍먹해본 사람이 있다면 지도학습이니 비지도학습이니에 대한 소리를 들어본 적이 있을 것이다. 
### Supervised Learning
지도학습에선 데이터들이 모두 라벨을 갖고 있다.
즉 입력과 정답 $(x,y)$가 함께 주어진다.

- **분류**: 스팸/정상처럼 이산적인 클래스를 예측한다.
- **회귀**: 주택 가격처럼 연속적인 값을 예측한다.

### Unsupervised Learning
비지도 학습에선 라벨이 없고, 모델이 숨겨진 패턴을 찾는다.
정답 없이 데이터의 구조를 찾는 것이다. 
- 군집화는 비슷한 샘플을 그룹으로 묶고
- 연관 분석은 함께 발생하는 항목이나 관계를 찾는다.

### Semi-Supervised and Self-Supervised Learning
준지도학습은 소량의 라벨과 다량의 무라벨 데이터를 함께 사용한다.<br>
자기지도학습은 데이터 일부를 숨기거나 변형한 뒤(pseudo label) 원래 정보 또는 관계를 정답으로 삼아 사람이 만든 라벨 없이 표현을 학습한다.

### Reinforcement Learning
강화학습에선 에이전트가 환경에서 행동하고 보상과 벌을 받으며 장기 누적 보상을 높이는 정책을 학습한다. 이는 정답 레이블을 한 번에 받는 문제와 달리 행동의 결과가 늦게 나타날 수 있다는 특징이 있다.

## 3. Classical Algorithms
이렇게 고전 ML의 알고리즘은 크게 이렇게 분류할 수 있다.
- Supervised
  - Regression(연속 출력)
    - Linear Regression
  - Classification(이산 출력)
    - Logistic Regression
    - k-Nearest Neighbors (KNN)
    - Decision Tree / Random Forest
    - Support Vector Machine (SVM)
- Unsupervised
  - k-Means Clustering
  - Principal Component Analysis(PCA)
 
### Linear Regression
그럼 우리 수많은 학생들을 괴롭혀온 선형회귀부터 보자.
선형회귀는 입력 특징의 가중합으로 연속값을 예측하는 것이 목표다.

$$\hat y=w^Tx+b$$

대표적인 손실은 평균제곱오차다.

$$MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2$$

오차가 큰 샘플을 제곱해 강조하므로 이상치에 민감하다. 예를 들어 집 크기로 가격을 예측할 때 특정 거래가 비정상적으로 비싸면 그 샘플이 학습 방향에 큰 영향을 줄 수 있다.

### Logistic Regression
다음은 로지스틱 회귀다. 로지스틱 회귀는 이진 분류를 목적으로 두고 있으며, 선형 점수를 sigmoid에 통과시켜 이진 클래스의 확률을 만든다.

$$\sigma(z)=\frac{1}{1+e^{-z}}$$

일반적으로 $p>0.5$이면 1번 클래스로 분류하지만, 실제 기준은 오류 비용과 데이터 불균형에 따라 조정할 수 있다.

### K-Nearest Neighbors
KNN은 새 샘플 주변에서 가장 가까운 $k$개의 학습 샘플을 찾고 분류에서는 다수결을 사용한다. 별도의 복잡한 학습이 거의 없다는 장점이 있지만, 예측 때 거리 계산이 많고 특징 스케일에 민감하다. 키를 센티미터, 몸무게를 킬로그램처럼 단위가 다르면 표준화가 필요할 수 있다.

### Decision Trees
Decision Tree는 특징에 대한 if-else 질문을 순서대로 적용해 데이터를 나눈다. 해석하기 쉽고 수치형·범주형 특징을 함께 다룰 수 있지만, 트리가 깊어지면 학습 데이터의 우연한 패턴까지 외워 과적합하게 된다.

### Random Forests
Random Forest는 서로 다른 표본과 특징을 사용해 여러 결정 트리를 학습한 뒤 예측을 투표 또는 평균으로 합친다. 단일 트리보다 안정적이고 과적합을 줄이는 데 유리하지만, 모델 전체의 결정 과정을 하나의 규칙으로 설명하기는 어려워진다.

### SVM
SVM은 두 클래스를 나누는 경계와 가장 가까운 샘플 사이의 **margin**을 최대화한다. 경계를 결정하는 샘플이 support vector다. 선형 경계로 분리하기 어려우면 kernel을 사용해 곡선 형태의 관계를 다룬다. Linear SVM은 단순한 데이터, Kernel SVM은 집단화된 데이터에 적합하다.

### K-Means and PCA
- **K-means**: 중심을 초기화하고, 각 샘플을 가까운 중심에 할당한 뒤 중심을 다시 계산하는 과정을 반복한다.
- **PCA**: 데이터의 분산이 큰 방향을 주성분으로 찾아 차원을 줄인다. 3차원 데이터를 2차원으로 시각화할 때 정보 손실을 줄이는 방향을 선택할 수 있다.

## 4. Rule(Logic)-Based AI and Learning-Based AI

| 항목 | 규칙 기반 | 학습 기반 |
|---|---|---|
| 지식 원천 | 사람이 작성한 규칙 | 데이터의 패턴 |
| 새 상황 적응 | 낮음 | 데이터가 충분하면 높음 |
| 해석 가능성 | 대체로 높음 | 모델에 따라 낮음 |
| 대표 예 | 전문가 시스템 | 신경망, 앙상블 모델 |

규칙 기반 시스템은 명확한 조건과 검증 가능한 추론이 필요한 좁은 영역에 강하다. 반면 현실의 이미지·음성·언어처럼 규칙을 직접 작성하기 어려운 문제에서는 학습 기반 방식이 유리하다. 이후의 신경망은 이 학습 기반 접근을 층별 표현 학습으로 확장한다.
